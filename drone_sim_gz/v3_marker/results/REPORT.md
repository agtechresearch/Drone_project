## 1. 대리 모델 (surrogate) — wk3/surrogate.py
- PX4 옆 방향 응답 식별(Gazebo 계단 2/5/10/20 cm, logs/sysid_212519): 2차 + 지연, wn 3.23 rad/s, ζ 0.385, 지연 50 ms, 맞춤 RMS 1.1 cm. 목표점을 한 번에 옮기면 30~45% 오버슈트.
- 교정(scripts/calibrate_surrogate.py)과 실제 적용값은 다르다(2026-11-01 정정).
  - 교정 격자는 τ 0.3 / 0.5 / 0.8 / 1.2였고, 최적점은 **τ=1.2**, 호버 흔들림 0.03 m/s²였다. 이 최적점이 Gazebo C면 스윕 18 비행과 맞춘 최대 오차 RMSE가 **1.56 cm**다(wk3/surrogate.py:17 기록).
  - 실제로 쓰는 대리 모델은 EKF가 VIO 점프를 흡수하는 지연을 **τ=1.0 s**로 둔다. τ=1.0은 교정 격자에 없던 값이고, 이 모델 자체의 RMSE는 **미측정**이다. 이전 문구 "τ 1.0 s … RMSE 1.56 cm"는 두 값을 한 결과로 잘못 이었다.
  - 교정에서는 앞/뒤 여유가 음수인 비행(랙 접촉, 거리 지표 포화)을 뺐다. 그래서 1.56 cm는 비접촉 비행에 대한 적합도이고, 접촉 사례는 안전성 평가에서 따로 봐야 한다.
  - scripts/validate_surrogate.py도 같은 스윕(yaw/drift/step)을 쓴다. 독립 holdout 검증이 아니다.
  - 큰 차이: 드리프트 0.8 보정 켬(대리 10.7 vs Gazebo 17.0 cm).
- 속도: 1 비행 0.02 s (Gazebo 대비 약 3,500배).

## 5. 결론 (1차)
1. 상대 비교 규칙(C2r, "이전보다 가까우면 멀어짐")은 기준이 계속 바뀌어 오차가 쌓임 → 목표 거리(절대) 기준이 필요.
2. 사각지대 + 쿨다운 규칙(C2/C3)은 C1보다 "임계값 초과 출력 변경 프레임 수"가 적고, 정확도는 C1과 비슷하거나 약간 나쁘다(2026-11-01 정정).
   - 이 계수는 결정 횟수가 아니다. 그래서 "보상 횟수 1/10~1/25 감소"나 과반응이 같은 배수로 줄었다는 일반화는 하지 않는다.
   - 총 offset 이동은 C1 0.4549487024126949 m, C3 0.43588574746078823 m로 비슷하다.
3. 이 설정으로 학습한 두 PPO 정책(C4a 잔차, C4b 단독)에서는 대리 모델상 이득을 확인하지 못했다. 측정이 없을 때의 행동이 위험해 안전장치가 필요하다(2026-11-01 정정).
   - 학습 보상 로그가 모두 NaN이고 학습 seed가 하나뿐이라 수렴은 미확인이다. 학습과 배포의 적분 시간 불일치도 있다.
   - 따라서 "강화학습 방식 자체가 이득이 없다"는 일반 결론은 아니다. 알고리즘 우열을 말하려면 독립 학습 반복과 조건별 실패율·분산이 필요하다(미수행).
4. 대리 모델 최적화 결과는 Gazebo로 그대로 옮겨지지 않음 → 대리 모델 잡음 교정 보강 또는 Gazebo에서 직접 소수 반복 최적화가 필요. 실기로 갈 때도 같은 문제(대리→Gazebo→실기)가 생기므로, 실기 관찰 모드 로그로 대리 모델을 다시 맞추는 절차가 핵심.
